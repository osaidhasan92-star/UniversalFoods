UNIVERSAL FOODS WEBSITE v2
===========================
This version is a TRUE multi-page static website inspired by the information architecture and navigation pattern of the current Mezzan site.

Included pages:
Home, About, History, Values, Leadership, Brands,
Business Lines, Food Trading, Distribution, Food Service, Products, Operations,
Investor Relations, Reports, Governance,
Social Responsibility, News, Careers, Contact.

Navigation:
- Desktop: hover dropdowns and nested flyout menus.
- Mobile/tablet: click/tap dropdowns and nested menus.
- Every page shares the same header/footer.
- All navigation links are real HTML pages; no SPA routing is required.

Branding:
Universal Foods logo supplied by the client.
Navy #0c2e4c, Gold #c9a14a, Green #2e8b57, Cream #f7f4ec.

Run:
Open index.html directly, or use VS Code Live Server.

Replace:
- Remote Unsplash image URLs in HTML with your own local images.
- Placeholder contact details.
- Demo statistics, news and product names with actual company information.
